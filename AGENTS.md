# Agent Instructions

## Mission

Japanese Learner is a personal Japanese learning app for travel readiness.
Preserve its existing learning flows unless the task explicitly changes them.

## Start here

Read the current task and any plan it references before choosing files.
Before changing code, tests, tooling, or documentation that describes implementation, read `CODING_STANDARDS.md`.
For optional CodeGraph navigation, read `documents/decisions/005-codegraph-repo-local-navigation.md` before indexing or querying.
Run `git status --short --branch` before choosing files and preserve existing changes.

## Follow the relevant guide

- Setup, environment, routes, or architecture: read the relevant section of `README.md`.
- Plans, decisions, or analyses: check `documents/INDEX.md` and read records relevant to the task.
- Writing project documents: read the documentation section of `documents/CONTRIBUTING.md`.
- Subagent work or maintenance: read the collaboration section of `documents/CONTRIBUTING.md`.
- Implementation, bug fixes, or software verification: read `docs/agents/engineering.md`.
- Domain language: `CONTEXT.md` and `docs/agents/domain.md`.
- Issue and label workflows: `docs/agents/issue-tracker.md` and `docs/agents/triage-labels.md`.

## Repository protections

Before editing, read the [branch and publication policy](documents/CONTRIBUTING.md#branch-and-publication-policy) and [validation and review](documents/CONTRIBUTING.md#validation-and-review) sections.
These sections cover branch, generated-file, coauthor, publication, validation, and review requirements.
